# 操作指南

本目录放**「具体怎么干」**：跑什么命令、看哪些现象、怎么留痕。只写步骤与判据，
不讲设计理由（理由住 的决策记录，契约住 `../architecture/`）。

## 本目录有什么

| 文档 | 什么时候读 |
| --- | --- |
| [验证与自证](验证与自证.md) | 改完代码要跑检查链、对比 pyflakes 增量、做隔离自证、给新门禁写自证时 |
| [真机验证清单](真机验证清单.md) | 改动涉及窗口层级 / 全屏 / 多显示器 / 热键 / 主题，要在 macOS 真机上目测验收时 |
| [设计令牌与组件目录](设计令牌.md) | 要加颜色令牌 / 改几何标尺 / 找可复用控件时，先查这张表再自己造 |
| [组件盒用法](组件盒用法.md) | 要写设置页 / 面板行 / 编辑屏，得知道调哪个函数、传什么参时 |
| [扩展点矩阵](扩展点矩阵.md) | 写插件要挂面板行 / 设置页 / 热键 / 动作按钮，或撞上「贡献被拒」时，先查这张表再读源码 |

两份的分工：**`验证与自证` 管「机器能判的」**（离屏 pytest ＋ pyflakes ＋ 目录快照），
**`真机验证清单` 管「只有人能判的」**（窗口服务器与 CGEventTap 行为）。

## 写作约定

- **常驻规程进本目录，批次状态不进**。当前待验的具体条目（带日期与背景）住
  §4 —— 那边是任务状态，会随批次滚动；本目录只放不随批次变的部分。
- 命令照抄可跑，别改成等价写法（等价写法常常少了一处关键参数，踩过的坑见 `验证与自证.md`）。
- 单文件 ≤ 300 行；超出按主题拆篇并在本表登记。
