# 组件盒用法

`barkit.shell.ui_kit` 是框架给设置页、面板、插件共用的控件盒。本篇只讲**调哪个函数、
传什么参**；颜色令牌与几何标尺住 [设计令牌](设计令牌.md)，这里不重复。

## 0 三条总则

1. **先查后造**。`python -c "from barkit.shell import ui_kit; print(ui_kit.__all__)"`
  看一遍再动手。造第二个「搜索框 / 勾选框 / 空态 / 反馈条」是本篇唯一禁止的事。
2. **样式归 `styles.py`、尺寸归 `metrics.py`**。组件盒只做装配：不写裸 `px`、不写
  十六进制色；要新尺寸就去 `metrics` 加常量（`test_no_qss_geometry_magic_numbers`
  与 `test_no_font_size_magic_numbers` 守这两条）。
3. **一个动作只有一个口**。搜索=`search_field`、勾选=`check_field`、按钮=`tool_button`、
  反馈=`FeedbackBar`、空态=`EmptyState`、下拉=`ChoiceSelector`。绕过它等于下一轮返工。

## 1 一页怎么搭

| 件 | 什么时候用 | 签名 / 返回 |
| --- | --- | --- |
| `settings_page_shell` | 新建一页设置页；要往页里插框架段的页**必须**用它 | `(title, parent=None) -> (page, layout)` |
| `settings_section` | 直接铺在设置页上的**分组卡**（自带面）；一组控件一张卡 | `(title, parent=None, *, collapsible=True, expanded=True) -> (card, body)` |
| `form_group` | **已有面的容器内部**分组（今天只有 `EditorShell`）；这里再铺卡就是面里有面 | `(title, parent=None, *, divider_above=False) -> (group, layout)` |
| `is_standard_shell` | 判这一页有没有可插的纵向布局 | `(page) -> bool` |
| `insert_page_slot` | 框架自动段（状态机）的落点：标题之下、组件内容之上 | `(page, widget) -> bool` |
| `insert_page_tail` | 框架区（运行间隔 / 配置维护 / 装置运维）的落点：组件内容之后 | `(page, widget) -> bool` |

框架画的东西**只许落在这两头**；两个插槽口返回 `False` ＝ 这一页不是标准外壳，调用方自行兜底。
`settings_section` 里行与行之间不必再插 `Divider`（卡本身就是分组，卡内用间距分段）；
`form_group(divider_above=True)` 只给**第二组及以后**用，第一组头顶那一刀是多余的。

```python
page, lay = ui_kit.settings_page_shell("通知守卫")
card, body = ui_kit.settings_section("装置")
body.addWidget(ui_kit.form_row("端口", ui_kit.NumberField()))
lay.addWidget(card)
```

## 2 一行表单

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `form_row` | 默认排法：一行一个设置项，标签定宽、左缘对齐 | `(label, control, parent=None, label_width=78, *, control_fill=True) -> QHBoxLayout` |
| `form_row_stacked` | 标签本身就长，横排放不下（**另一种排法**，不是上面那种的特例） | `(label, control, parent=None) -> QWidget` |
| `form_label` | 只需要一枚标签、不组行 | `(text, parent=None) -> QLabel`（caption 档） |
| `choice_hint` | 下拉下面那句「**当前选中项**」的释义；收的是**真 `QComboBox`**（`ComboField` 一类，`ChoiceSelector` 是包装件、没有 `currentIndexChanged`） | `(combo, hints, parent=None) -> QLabel` |
| `note` | 小字说明（竖直钉住，不随窗口变高） | `(text, parent=None) -> QLabel` |

`control_fill` 判的是**控件性质**、不是排版偏好：全宽输入（`QLineEdit` / `QTextEdit`）留默认
`True`；窄取值（端口格 / 毫秒格 / 下拉）传 `False` —— 它贴到行尾、余量给标签（此时
`label_width` 不生效）。`choice_hint` 的 `hints` 以**取值**（`itemData`）为键，缺键当场报错
（空释义比没有更糟）。

## 3 取值控件

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `ChoiceSelector` | 选项较多 / 就用下拉；`choices` 是 `[(取值, 显示名)]` | `(choices, current=None, parent=None)` |
| `ChoiceBar` | 选项少、一行摊得开，**要横向并排看得见**时 | `(choices, current=None, parent=None, *, hints=None)` |
| `ProfileSelector` | macOS 输入法源那类「默认输入项」 | `(names, current, parent=None)` |
| `ComboField` / `NumberField` / `DecimalField` | 设置页的输入格；滚轮**只滚页面**、不改值（Decimal 一位小数） | `(parent=None)` |
| `Switch` | 意象是「**开关**」；**不翻自己**：`setChecked` 只写状态，翻由消费者做 | `(parent=None)` |
| `check_field` | 意象是「**勾选**」；Qt 自己翻并 `emit toggled(bool)` | `(text, *, checked=False, on_toggled=None, parent=None)` |
| `search_field` | 「输入即筛选」的唯一口；`on_changed` 拿**原文**（不 strip、不转小写） | `(placeholder="搜索", *, on_changed=None, parent=None) -> QLineEdit` |

`Switch` 与 `check_field` **不互相替代**，按意象选（开关 vs 勾选）。落盘时机由**接线**决定
（`on_toggled` 里直接写盘，还是交给保存键统一提交），与控件形态无关。`on_toggled` 拿到的是
翻转后的**新值**，别回头用 `isChecked()` 反推。

## 4 列表与行

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `StatusRow` | 状态行：图标 + 名称 + 副标题（竖向），右侧 0–2 个控件；`set_sub(text)` 改副标题 | `(icon, name, controls=(), badge=None, on_click=None, clickable=False, extra_refresh=None, parent=None)` |
| `RecordRow` | 列表里**一条记录**；`set_title/set_subtitle/set_icon/set_badge/add_trailing` | `(*, title="", subtitle="", icon=None, icon_fallback=None, badge=None, on_click=None, clickable=False, icon_tone="accent", margins=(14, 8, 14, 8), extra_refresh=None, parent=None)` |
| `HoverRow` | 上面两个的行骨架（自绘 hover 底色）；只在要造**第三种**行时才直接用它 | `(on_click, combo=None, clickable=True, parent=None)` |
| `EmptyState` | 空列表 / 无搜索结果 / 未识别的**唯一**占位；`hint` 是第二行小字 | `(text="", hint="", parent=None)` |

`icon` 取 `icons` 的名字；`icon_tone` 取 `ICON_TONES` 的键（`neutral` / `accent` / `solid`）。
**整行点击的 `on_click` 里要回访宿主，必须走 `defer_result_to_host`**（见 §7）。

## 5 按钮

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `tool_button` | 造按钮的唯一口。`kind`=objectName（`primary` / `pill-ghost` / `danger`…，**颜色归 QSS**）；`size`=档位 `action` / `inline` / `chip` | `(text, kind="pill-ghost", *, size="action", expanding=False, parent=None) -> QPushButton` |
| `apply_button_tier` | 已有 `QPushButton` **子类**（如 `MenuButton`）挂档位；返回该档高度 | `(btn, size="action") -> int` |
| `MenuButton` | `MenuSpec` 的渲染器：显示**当前项**，点击只 `emit clicked` | `(label="", parent=None)` |

**调用方不报数字**：高度、字号、内边距全由档位给（`metrics.BUTTON_HEIGHTS`），传没登记的档名
当场报错。`apply_button_tier` 必须在控件**首次 polish 之前**调 —— 显示过再改 `tier`，不
unpolish/polish 就仍按旧档画。

## 6 反馈与确认

`FeedbackBar`：**一页一条**，`addWidget` 到页面底部（或由 `EditorShell` 的动作行接管）。

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `info` / `warn` / `error` / `hint` | 报结果：成了 / 成了但差一步 / **没成** / 什么都没发生（「先勾一项」） | `(text)` |
| `ask` | 就地二次确认（原位长出按钮，不弹窗） | `(text, confirm_label, on_accept, cancel_label=None, on_cancel=None, confirm_kind="ghost")` |
| `dismiss` / `clear` / `text` / `tone` / `is_pending` | 收口与只读查询 | `()` |

`confirm_kind` 判据是「按下去会发生什么」：**不可逆**（删除 / 卸载 / 清空 / 覆盖 / 恢复默认）
用 `danger`（实心红），一般确认用 `primary`（实心紫），不确定就留 `ghost`。
**宿主面的确认一律行内**，别走浮层（浮层落点会被设置窗挡死，理由见设计令牌 §5.3）；没有槽位
（页面已销毁）⇒ 记 warning 并**拒绝执行**不可逆动作。

## 7 动作结果回传

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `relay_action_result` | **行内控件 / 候选菜单项**：当场跑回调，并把 `ActionResult` 交给面板 | `(widget, cb)` |
| `defer_result_to_host` | **整行点击**：晚一拍再回访宿主 | `(owner, result)` |
| `present_to_host` | 结局已经拿到了，只往上找宿主 | `(widget, result)` |
| `clear_layout` | 「重画一整组控件」的唯一清理口（子布局里的控件也一起摘） | `(layout)` |

宿主侧唯一约定是 `present_action_result`（鸭子类型：有这个方法就能接结果）。整行点击**别**用
`relay_action_result` —— 在控件自己的事件栈里回访宿主会崩（取证见
）。`clear_layout` 是 `setParent(None)` ＋
`deleteLater()` **两件都做**：只做后者，重建那一帧新旧控件同时可见。

## 8 编辑屏

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `EditStack` | 列表屏 ⇄ 编辑屏换屏容器：`push(screen)` / `back()` / `drop(screen)` / `current()`，信号 `screen_changed` | `(list_page, parent=None)` |
| `EditScreen` | 「点一行进来改这一条」的标准编辑屏：`add_group` / `add_action` / `add_destructive` / `set_hint` / `stretch_content` | `(*, title="", back_label="‹ 返回", save_label="保存", on_validate=None, on_commit=None, parent=None)` |
| `EditorShell` | 四区外壳本体（导航带 / 内容滚动区 / 提示 / 动作行）；一般直接用 `EditScreen`，别自己拼四区 | `(title, parent=None, *, hint="", back_label="返回")` |

`EditScreen.add_group()` 是 `form_group` 的口（**没有底色**）—— 别在它里面再套
`settings_section`。

## 9 底层自绘与文本

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `Card` | 需要一块**面**时（实心 surface ＋ 1px 描边，无投影） | `(radius=14, parent=None, *, bg_token="surface", border_token="border")` |
| `Divider` | 1px 分割线，横向铺满父布局 | `(parent=None)` |
| `ElideLabel` | 单行、超宽以省略号截断（不换行） | `(text="", parent=None)` |
| `LogoWidget` | 面板头部品牌标记（渐变方块 ＋ 白色条形码） | `(size=26, parent=None)` |
| `HStatChip` | 标题栏 `● 状态文字` 芯片；`set_state(text, level)` | `(text="", level="idle", parent=None)` |
| `ModeBadge` | 「自动 / 手动 / 已接管」模式徽标；`set_state(label, accent)` | `(label="", accent=True, clickable=False, parent=None)` |
| `apply_text_role` | 套**排版角色**（`caption` / `status` / `note` / `section` / `page_title` / `row_title` / `detail_title` …）；`color` 传**令牌名** | `(widget, role, *, color=None)` |
| `note` | 小字说明（见 §2） | `(text, parent=None)` |

`apply_text_role` 只写 `styleSheet`（尺寸 / 光标 / `objectName` 仍归调用方）；角色名拼错**当场抛错**。
**别改用 `QPalette` 换色** —— QSS 的 `color` 优先级更高，设了也一个像素不生效。烤主题色的件要
自己实现 `refresh_theme()` 并订阅 `theme_changed`。

## 10 图标与入场

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `glyph_pixmap` | 给控件资源接口（`setIcon` / `setPixmap`）渲染一枚字形 | `(target, icon, size, color) -> QPixmap` |
| `draw_glyph` | 自绘 `paintEvent` 里画主字形（**唯一出口**） | `(painter, icon, rect, color)` |
| `badge_glyph_pixmap` / `draw_badge_glyph` | 带角标的字形（pixmap 版 / 自绘版） | `(target, icon, level, size, color)` / `(painter, icon, level, rect, color)` |
| `play_entrance` | 顶层窗入场淡入；只在原生 cocoa 生效，其余环境 no-op | `(win)` |
| `qt_alive` | 判 C++ 本体还在不在（晚一拍回执前先判活） | `(obj) -> bool` |

## 11 菜单

| 件 | 什么时候用 | 签名 |
| --- | --- | --- |
| `CandidateMenu` | 候选列表弹层（原生 `QMenu` 外壳）：`popup_at(pos, anchor_rect=None)` / `pick(index)`，信号 `picked` | `(items, current="", parent=None, on_picked=None)` |
| `MenuItem` | 候选项的值对象（`label` ＋ `hint`，来自 `contribution.specs_controls`）—— **别往里塞闭包**，冻结值对象塞闭包会连出一片引用环 | 数据类 |

菜单里一条的 `on_click` 由 `CandidateMenu.pick` 以**弹层自己**为起点中继，插件原回调保持不动。

## 12 别做

- 别在插件 UI 面（`plugins/**`）新建 `QPushButton` / `QComboBox` / `QCheckBox`：
  零存量门禁在扫，改用 `tool_button` / `ChoiceSelector` / `check_field`。
- 别在调用方写裸 `px`、十六进制色、`setFixedHeight(数字)`；尺寸与颜色各有单一真源。
- 别把「`QLineEdit` ＋ 占位文案 ＋ 清空键 ＋ `textChanged`」再手搓一遍 —— 那是 `search_field`。
- 别造第二个空态、第二个反馈条、第二个确认弹窗（浮层只有询问中枢那一个）。
- 别把业务判断塞进组件盒：它只做**装配**，不做决策。
