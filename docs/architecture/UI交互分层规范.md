# BarKit UI 交互分层规范 · v2.0

> 版本：v2.0 · 日期：2026-09-09
> 上游文档：`主框架架构.md`（v3.0）—— **本文依赖它的契约层，不重复定义**
> 评审沉淀：`两份方案联合评审-v1.md`（历史评审稿，已从 docs 移除，结论已并入 v3 主方案，可从 git 历史恢复）
>
> **v2.0 相对 v1.8 的变化**：v1.8 的设计判断都对，但它是在框架方案 v1 的目录结构上写的，与 v3.0 有 6 处契约级冲突。v2.0 做四件事：
> 1. **明确与框架方案的边界** —— 本文只管「怎么画 + 画什么位置」，Spec 的数据结构和状态流一律以框架方案 v3.0 为准。
> 2. **修正状态模型** —— `StateSpec` 只留静态字段，动态数据（level / summary）走 `StateReport`，避免状态流出现第二条路径。
> 3. **改判深度入口规则** —— 原「一个插件只能有一种深度入口」会吃掉框架方案批次 3 的收益，改为「同一类配置只在一处可改」。
> 4. **补齐可落地三件套** —— 门禁测试、批次落点、现有折叠机制与存量失败测试的处置。
>
> v1.8 的视觉规格（令牌、圆角、字体、组件结构）经逐项核对与代码一致，**全部保留**。
