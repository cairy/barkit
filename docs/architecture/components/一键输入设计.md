## 设计要点

- 收编现有脚本：CGEvent Unicode 直注 + TIS 输入法检测/切 ABC + 倒计时，逻辑不变。
- 交互改造：终端倒计时 → 托盘触发后弹轻量浮层倒计时（可取消），倒计时内切到目标窗口聚焦。
- **倒计时为 profile 级配置**：每个 profile 可单独设 `delay`（切换到目标窗口所需时间不同），未设置时回退全局默认值。
- 支持"自动触发指定文字输入"：配置多个 profile（名称+文字+可选回车），托盘子菜单/热键直选。
- 内容不限于密码，任意明文文本均可（如常用口令、固定文本）。
- **存储**：直接存 YAML 配置（明文），暂不进 Keychain；app 写配置时自动 `chmod 600`。
- **已知限制**：开启 Secure Event Input 的应用（1Password、部分银行/密码框）收不到注入事件，静默失败；README 写明（cloudclient 已验证，不影响 v1）。
- **配置方式**：提供 UI 配置窗口（profile 增删改、延迟/回车等参数），改完写回 YAML。

## 配置段（示意）

```yaml
plugins:
  autotype:
    enabled: true
    delay: 4                  # 全局默认倒计时（秒）
    interval: 0.03            # 全局默认逐字符间隔（秒）
    press_enter: false        # 全局默认输完后是否回车（profile 可覆盖）
    enter_delay: 0.3          # 输完到回车之间的等待（秒）
    auto_switch_ime: true     # 非英文布局时自动切 ABC
    profiles:
      - name: cloudclient
        text: "xxxx"          # 明文，可为密码也可为任意文本
        press_enter: true
        delay: 6              # 可选：覆盖全局倒计时，该 profile 专属
      - name: wifi
        text: "yyyy"
        press_enter: true     # 未写 delay → 用全局 4 秒
```

## 实现约束（来自 `../README.md` 调度与线程模型，原 方案文档 §3.4）

- 倒计时浮层属于 UI 内部交互用途，生命周期跟随窗口，**不属于后台轮询**，不归入 scheduler 的 `QTimer`/`while True` 禁令范围。
- 明文配置写入一律走 `core/config`（原子写 + `chmod 600`），与手编 YAML 同一入口、同一校验（见 `../README.md` 配置体系）。
