## 2.6 行内控件：行右边的开关

组件列表行右侧可以挂控件，声明在 `row_specs()` 返回的 `StatusRowSpec.controls` 上，**0–2 个**：

| 控件 | 形态 | 运行时重读 |
|---|---|---|
| `SwitchSpec` | 开关 | `get_checked` 重读开关态、`get_enabled` 重读可用态 |
| `MenuSpec` | 点击弹出菜单（注意：是弹菜单，不是下拉框） | `get_items` 重读候选项、`get_current` 重读当前项 |
| `ButtonSpec` | 按钮（`ghost` / `primary` / `danger`） | — |
| `ChoiceSpec` | 行内下拉选择器（**切换只改选中，不执行动作**） | `get_items` 重读候选项、`get_current` 重读当前项、`get_enabled` 重读可用态 |

```python
controls=(
    SwitchSpec(
        checked=self._switch_checked(),
        on_toggle=self.toggle_switch,
        get_checked=self._switch_checked,                    # 外部改动后同步开关态
        get_enabled=lambda: self._rule_name() is not None,   # 没装守护时灰掉开关
    ),
)
```

「守护没装 → 开关灰掉」这类**动态可用性用 `get_enabled` 回调表达**；`get_checked` 同理负责动态开关态。

### 菜单：候选项必须带上下文

```python
MenuSpec(
    items=(
        MenuItem("自动",      self.use_auto,   hint="按网段匹配"),
        MenuItem("office",    self.use_office, hint="192.168.11.0/24 · 3 条路由"),
        MenuItem("iPad 直连", self.use_ipad,   hint="仅手动 · 静态"),
    ),
    current="office",                    # 选中项（对应 MenuItem 的 label）
    get_items=self._menu_items,          # 候选项随配置变时用回调重读
    get_current=self._menu_current,      # 当前项同理
)
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `items` | 是 | `MenuItem` 序列。每项 = `label` + `on_click` + 可选 `hint` |
| `current` | 否 | 当前选中项，**按 `label` 匹配**；不填则都不选中 |
| `get_items` | 否 | 运行时重读候选项。候选集合会随配置变化时必须给 |
| `get_current` | 否 | 运行时重读当前项 |

**菜单项必须能带副文案（`hint`）。** 用户是在"选哪个"的时刻需要上下文：
「office」只是个名字，看不出它管哪个网段、带几条路由——**只给名字的菜单等于没有信息**。
`hint` 显示在 `label` 下方或右侧（形态见 UI 规范），不参与选择。

**候选集合可以来自运行时**：`get_items` / `get_current` 与 `get_checked` / `get_enabled` 同款——
纯读取、每次刷新求值（见 3.1）。不声明它们时用静态的 `items` / `current`。

### 下拉：切换只改选中，动作归整行点击

```python
ChoiceSpec(
    get_items=self._profile_names,      # 候选项（显示名）
    get_current=self._choice_current,   # 当前项（按显示名匹配）
    on_change=self._choice_remember,    # 选中变化通知（**不是动作**）
    get_enabled=self._has_profiles,
    tooltip="选一项，点整行即输入",
)
```

与 `MenuSpec` 的分界是**弹菜单是动作、下拉是状态**：

- `MenuSpec`：点开列表，**选一项就执行那一项的动作**（每项自带 `on_click`）；
- `ChoiceSpec`：持久显示当前项，**切换只改选中**——业务动作挂在整行 `on_click` 上。

| 字段 | 必填 | 说明 |
|---|---|---|
| `items` / `get_items` | 否 | 候选**显示名**；会随配置变时给回调 |
| `current` / `get_current` | 否 | 当前项，按显示名匹配 |
| `on_change` | 否 | 选中变化的**通知**，插件拿它记住选中项；不要在里面执行业务 |
| `enabled` / `get_enabled` | 否 | 可用态（无候选时灰掉） |
| `width` | 否 | 0 = 由内容自然宽度定 |

**它存在是为了消掉一类逃生舱**：在它之前，行内要一个下拉框只能走 `StatusRowSpec.custom`
自己拼一行，于是行的尺寸 / 对齐常量出现第二份、与框架那份各自漂移（2026-09-20 实修：
自绘行 30 盒 / 16px / 左对齐，框架行 36 盒 / 22px / 居中，界面上表现为那一行图标小一圈
且贴左）。这类「尺寸漂移」改字形永远改不掉——差在容器，不在字形。

行内控件放**高频、二元、即时**的东西；低频、多字段、需要「保存」的配置放**设置页**（`SettingsPageSpec`，见 2.8）：

| | 行内 `controls` | 设置页 |
|---|---|---|
| 放什么 | 开关、模式、下拉选择 | 表单、多字段、任务流 |
| 用户什么时候用 | 每天都点 | 配一次就不再动 |
