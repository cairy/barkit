## 已实现现状（2026-08 落地，as-built 基线）

> 本节记录本重设计提案定稿前的**原始 route_guard 已实现形态（方案 A）**，作为"现状基线"。
> helper 协议（`HELPER_VERSION`）、规则语义、trigger 机制在本重设计后仍沿用；场景化网卡配置由本文前述设计取代。来源：（2026-09-15 从原方案文档并入本文件「已实现现状」节）。

### 核心思想

把唯一的 root 操作隔离成一个极小的 LaunchDaemon helper，一次性安装后永久自动运行。

```
[一次性] UI 点"安装路由守护" → osascript with administrator privileges
  → 安装 /Library/LaunchDaemons/com.barkit.routed.plist
  → helper 脚本复制到 /Library/Application Support/BarKit/（root 所有）
[常驻] root helper（KeepAlive，崩溃自动拉起）：
  ├─ 触发：常驻轮询（默认 30s）+ 会话上有事即立刻跑一轮（意图更新 / `resync` 命令 / 新连接补发）
  ├─ 每轮取内存里那份**路由意图**（app 经会话声明，不落盘），逐条判断：接口 up？当前网关匹配？
  ├─ 匹配 → 幂等添加（route -n get 先查，存在跳过）
  │  不匹配 → 删掉该规则此前添加的路由
  └─ 结论经会话**推**给订阅方（`event.push("route", …)`），不落盘
[UI] route_guard 插件：订阅「路由」领域 → 读内存里那份事实 → 逐条显示；
  提供手动"立即检查"（`op.run("resync")`）、安装/卸载守护
```

### 数据流与文件域（评审修正 → 2026-09-29 改为会话）

规则与状态**都不落盘**（从前是用户域 `routes.json` / `state.json` / `.trigger`）：期望态是会话上
`intent.set("route", …)` 的一帧，观测是 `event.push("route", …)` 推回来的一帧。这样「改规则零授权」
依然成立（授权只发生在安装守护那一次），而且省掉了「写文件 ＋ 监视目录 ＋ 每秒查 trigger」这一整套。
唯一落盘的是守护的崩溃恢复快照 `helper_snapshot.json`（只在内容真变时写）。

### 规则语义

一条规则 = "当处于某条线路（iface + gateway）时，把去往哪些目标网段/主机的流量走这条线路的网关"。

- `iface` + `gateway`：**触发条件**（非路由本身）。仅当该接口在线且当前网关匹配时才执行。
- `destinations`：**路由目标**，支持列表；单个主机用 `/32`。
- 可配置任意多条规则，互不冲突；若 destinations 重叠且同时匹配，按 `priority` 顺序执行（小者先），后者覆盖前者。

### 关键点

- 路由重启后丢失，LaunchDaemon 开机自动拉起正好补上——天然解决持久化。
- 触发方式定案：常驻纯轮询（launchd 无"网络变化事件"原生触发；WatchPaths 监听 SystemConfiguration 不可靠）；路由增删幂等 + 场景切换不要求秒级响应。
- "立即检查"机制：走会话上的 `resync` 命令（从前是 app `touch` 一个 trigger 文件、helper 每秒查一次），守护当场跑一轮。
- 容错：helper 收到不认识的意图（版本不符 / 字段非法）时保持上一轮路由不动，并把错误随观测推回来。
- 安全：helper 对规则文件做 schema 校验（非法字段整份拒绝）；执行仅用参数化 subprocess 调 `route`，禁止 shell 拼接。
- 版本锚点：helper 脚本头部 `HELPER_VERSION`，app 启动时正则提取与内置期望值比对，过期提示重装。
- 网关检测兜底：`ipconfig getpacket` 对静态 IP 接口无返回 → 降级用 `route -n get default` 获取网关。

### 配置段（示意）

```yaml
plugins:
  route_guard:
  enabled: true
  poll: 30
  rules:
  - name: office
  priority: 1
  iface: en5
  gateway: 10.8.195.254
  destinations:
  - 10.1.51.0/24
  - 10.2.0.0/16
  - 192.168.100.5/32
  - name: home
  iface: en6
  gateway: 192.168.2.1
  destinations:
  - 172.16.0.0/16
```

### helper 生命周期约定

| 场景 | 行为 |
| --- | --- |
| app 更新，规则变化 | 无需重装：app 改完即把新意图推过去，helper 下一轮生效 |
| app 更新，helper 逻辑变化 | app 启动时比对 helper 版本，过期提示"一键重装"（一次授权） |
| 正常卸载 | UI 提供卸载按钮：bootout daemon + 删 plist/helper + 按守护**此刻**回报的观测清理已加路由（回报缺失时宁不清理，不误删） |
| app 被直接删除 | daemon 残留但已无意图来源则行为可预期；文档提供手动清理命令兜底 |
